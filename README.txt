بازارینو V5 — اپ PWA قابل نصب
1) فایل‌ها را روی یک هاست یا localhost قرار دهید.
2) index.html را باز کنید.
3) در مرورگر موبایل گزینه Add to Home Screen / نصب برنامه را بزنید.
نکته: برای Service Worker باید از https یا localhost استفاده شود؛ file:// ممکن است نصب PWA را فعال نکند.
این نسخه Frontend آزمایشی است و برای پرداخت واقعی، احراز هویت و دیتابیس باید Backend اضافه شود.
